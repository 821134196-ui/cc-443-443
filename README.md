# 商场母婴室巡检与耗材补给系统

面向商场后勤值班人员的一体化管理系统：楼层房间与设施管理、移动逐项巡检、不可覆盖班次快照、
耗材自动补给、维修复测闭环、临时闭用与顾客报障、分级升级。**仅使用 Python 标准库 + SQLite，
零第三方依赖，离线可运行。** 不采集顾客真实身份（顾客报障只需描述故障，无姓名/电话字段）。

## 一条命令启动

```bash
./start.sh
# 或：python3 run.py --reset
```

自动导入巡检样例数据并启动，浏览器打开 <http://127.0.0.1:8077>（端口可用 `MB_PORT` 修改）。

- 前端为随服务托管的静态页面（`app/static/`，原生 JS，无需构建/无需 node_modules）
- SQLite 数据库：`app/data/mall_nursing.db`；故障照片：`app/data/photos/`
- 重置样例：`python3 run.py --reset`

## 六个工作视图

| 视图 | 能力 |
|---|---|
| 楼层总览 | 紧凑房间条目，左侧色条标识开放/局部/闭用，设施开放度、低库存、工单数一目了然；升级事件按负责人置顶 |
| 移动巡检 | 六项逐检（门锁/水温/插座/异味/清洁度/耗材余量），大按钮单手操作；一键读取模拟水温；消毒登记；库存步进器与实心刻度 |
| 设施状态 | 尿布台/哺乳隔间/热水设备开闭与原因，房间级/设施级临时闭用，顾客报障入口 |
| 补给队列 | 低库存自动入队；**领料→送达→上架三步分别确认**；时限倒计时与超时标记；撤销上架主管复核 |
| 维修复测 | 故障照片清晰大图（点击放大）；开始维修→复测通过才重开，未通过保持关闭 |
| 班次交接 | 全部房间生成快照后方可交班；汇总快照、未结工单、补给、升级、提醒 |

## 核心业务规则

- **班次快照不可覆盖**：六检齐全才能生成；SQLite 触发器禁止 `UPDATE/DELETE` 四张快照表。
- **局部闭用**：热水/单个隔间故障只关对应设施，房间变 `partial`，其余隔间继续使用；
  门锁、插座等安全项故障才整间闭用。
- **维修复测**：故障自动建工单关设施；复测通过才解除闭用（重算状态），未通过继续关闭。
- **低库存补给**：库存 < 安全量自动建补给单（幂等）。三步状态机不可跳步。
- **并发领单**：`BEGIN IMMEDIATE` + 条件 `UPDATE ... WHERE status='queued' AND claimed_by IS NULL`，
  两人同时领取只保留首个成功者，另一人收到明确 409 提示。
- **五类升级，不同负责人**：

  | 类型 | 负责人 |
  |---|---|
  | 缺货替代（库存为 0） | 补给主管 supply_lead |
  | 热水超温（>45°C 适配器读数） | 设备工程师 engineer |
  | 消毒漏项（快照时发现缺登记） | 卫生负责人 hygiene_lead |
  | 连续报障（同对象 24h 内 ≥2 次） | 值班经理 duty_manager |
  | 整间闭用 | 楼层管理员 floor_manager |

- **温度模拟适配器**：`app/temperature.py`，确定性抖动 + 场景脚本/环境变量覆盖；
  演示超温：`POST /api/facilities/<id>/temperature/override {"value_c":48.6}`（传 `null` 清除）。
- **进程内任务**：补给时限（纸巾 4h、清洁袋 6h）与复检提醒（24h）落库 `reminders`，
  后台线程每 20 秒检查到点触发。
- **跨楼层权限**：值班员工绑定授权楼层，越层操作返回 403；主管/专项负责人全楼可见。
- **顾客隐私**：`customer_reports` 表无任何身份字段，报障接口不要求登录。

## 目录结构

```
app/
  schema.sql       表结构 + 快照不可变触发器
  db.py            连接/事务锁/楼层权限
  config.py        巡检项、阈值、升级路由、时限
  temperature.py   模拟温度适配器
  services.py      全部领域逻辑
  server.py        stdlib HTTP（JSON API + 静态/照片托管 + 后台提醒线程）
  seed.py          样例数据（含在修工单、低库存、连续报障、超温场景）
  static/          index.html / styles.css / app.js
tests/test_system.py
run.py / start.sh
```
